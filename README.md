# MP3_TagReader_-_Editor
The MP3 Tag Reader & Editor project in C is a console-based application used to read, display, and edit metadata information stored in MP3 audio files. This project is developed using the C programming language and demonstrates concepts such as file handling, structures, strings, pointers, and binary file operations.

## Features
* Read MP3 tag information
* Display song details
* Edit MP3 metadata
* Update artist and album name
* Modify song title and genre
* File handling using binary files
* User-friendly menu-driven interface

## Technologies Used
* C Programming Language
* File Handling
* Binary File Operations
* Structures
* Functions and Pointers

## Project Structure
* `main.c` → Main function and menu operations
* `tagreader.c` → Reading MP3 tag details
* `tageditor.c` → Editing MP3 metadata
* `file.c` → File handling operations
* `tagreader.h` → Header file for tag reading
* `tageditor.h` → Header file for tag editing
* `common.h` → Common declarations and structures
* `sample.mp3` → Sample MP3 file
* `makefile` → Used for compilation
